# Basic Plugin (React)

A React-based plugin example for LottieFiles Creator.

## Install

```bash
npm install
```

## Development

```bash
npm run dev
```

Starts a local HTTPS dev server with hot module reloading.

## Build

```bash
npm run build
```

Creates production files in the `dist/` folder:

- `manifest.json` - Plugin metadata
- `plugin.js` - Plugin code
- `ui.html` - React UI
